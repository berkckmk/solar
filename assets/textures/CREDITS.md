# Planet texture credits

Surface maps by **Solar System Scope** (https://www.solarsystemscope.com/textures/),
based on NASA mission imagery, licensed under
**Creative Commons Attribution 4.0 International** (https://creativecommons.org/licenses/by/4.0/).

Changes: the `4k_*` files are resized from the 8K originals (JPEG, quality 90); the Earth cloud
and specular maps are stored as greyscale. The `2k_*` files are unchanged apart from re-encoding.
`tools/download_textures.py` fetches the unmodified 8K originals (git-ignored).

Suggested line for the video description:

> Planet textures: Solar System Scope (solarsystemscope.com), CC BY 4.0, based on NASA data.
